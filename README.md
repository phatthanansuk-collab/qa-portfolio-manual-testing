# QA Portfolio - Manual Testing

ยินดีต้อนรับสู่ Repository นำเสนอผลงานและทักษะด้าน **Manual Testing** ของฉัน 
โดยโปรเจกต์นี้จัดทำขึ้นผ่านการทดสอบเว็บแอปพลิเคชันจำลอง เพื่อเตรียมความพร้อมสำหรับการทำงานจริงและการสมัครงานสหกิจศึกษา/ฝึกงาน

---

## 🎯 Project: The Internet (Login System)

โปรเจกต์นี้เป็นการทดสอบระบบเข้าสู่ระบบ (Login System) เพื่อสาธิตและฝึกฝนทักษะการทำ **Manual Testing** พื้นฐาน ตั้งแต่การออกแบบ Test Case, การทดสอบฟังก์ชันการทำงาน, การคัดแยกและรายงานบั๊ก (Bug Report) ไปจนถึงการจัดทำเอกสารหลักฐานการทดสอบ

🔗 **เว็บไซต์ระบบทดสอบ:** [The Internet - Login Page](https://the-internet.herokuapp.com/login)



## 🛠️ Skills & Tools (ทักษะและเครื่องมือที่ใช้)

### Testing Skills
- **Test Case Design:** การออกแบบเคสการทดสอบที่ครอบคลุมเงื่อนไขต่างๆ ทั้ง Positive & Negative Test
- **Functional Testing:** การทดสอบฟังก์ชันการทำงานของระบบให้ตรงตาม Requirement
- **Bug Reporting:** การรายงานและการบันทึกบั๊กอย่างเป็นขั้นตอนพร้อมระบุระดับความรุนแรง
- **Test Documentation:** การจัดทำเอกสารและสรุปผลการทดสอบอย่างเป็นระบบ

### 🧰 Tools Used
- **Microsoft Excel / Google Sheets:** จัดทำเอกสาร Test Case และ Bug Report
- **GitHub:** จัดเก็บไฟล์และนำเสนอผลงาน Portfolio



## 📦 Deliverables (สิ่งที่จัดทำในโปรเจกต์)

- **Test Case:** เคสการทดสอบระบบ Login ที่ครอบคลุมทุกเงื่อนไข
- **Bug Report:** เอกสารรายงานปัญหาที่พบพร้อมรายละเอียดและระดับความสำคัญ (Priority/Severity)
- **Screenshot Evidence:** ภาพถ่ายหน้าจอหลักฐานการทดสอบและข้อผิดพลาดของระบบ
